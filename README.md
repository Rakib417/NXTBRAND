# NXTBRAND

Static Next.js version of the WordPress site **NXTBRAND**, generated by the PressBake plugin.
The live site needs no WordPress, PHP or database: it is plain files served by a CDN.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
npm run preview  # serve out/ locally
```

## What is in here

| Path | What it is | Owner |
|---|---|---|
| `src/app/` | Routes, layout and 404 page | you |
| `src/components/` | `WpPage` renders a page from its JSON | you |
| `src/lib/` | Route lookup and attribute helpers | you |
| `scripts/postbuild.mjs` | Sets each page's `<html lang/dir>` and `<body class>` after the build | you |
| `src/content/pages/*.json` | One file per page: head tags, body HTML, language | plugin |
| `src/content/routes.json` | Every route and its data file | plugin |
| `src/content/wp/*.json` | Posts, pages, menus, taxonomies, site info as plain data | plugin |
| `public/` | Theme files, images and uploads, `robots.txt`, `sitemap.xml`, `_redirects` | plugin |

Files marked **plugin** are rewritten every time you publish from WordPress (they are listed in `.pressbake.json`).
Files marked **you** are created once and never overwritten, so you can change them freely.
To get a fresh copy of them, turn on "Overwrite code files" in the plugin's GitHub settings for one publish.

## Deploy

Connect this repository to your host once; every push from WordPress then goes live automatically.

| Host | Build command | Output folder |
|---|---|---|
| Vercel | `npm run build` (auto-detected) | `out` (auto-detected) |
| Cloudflare Pages | `npm run build` | `out` |
| Netlify | `npm run build` | `out` |

## Limits of a static site

- Forms post to the form service set in the plugin (Formspree, Web3Forms, Basin...). Without one they do not send.
- WordPress search, comments, logins, carts and other per-visitor features do not exist on a static site.
- Content changes go live when you publish from WordPress, not instantly.
